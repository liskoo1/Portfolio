# Portfolio Luis Requena Mellado — Cinematic Redesign

Este es mi portfolio personal, originalmente creado en abril de 2024 y recientemente rediseñado con una estética **"Cinematic Dark"** (inspirada en la interfaz premium de expedition33.com).

## ✨ Características del Rediseño
- **Estética Dark Premium**: Fondo profundo oscuro (`#0A0A0A`) con acentos dorados/bronce (`#C9A96E`).
- **Glassmorphism**: Tarjetas translúcidas con bordes sutiles y efectos de desenfoque de fondo.
- **Scroll-Reveal Animations**: Aparición progresiva (fade-in-up) impulsada por IntersectionObserver.
- **Video Modal Cinemático**: Reproductor integrado para visualizar demos de proyectos.
- **Responsive Design**: Completamente adaptable a dispositivos móviles, tablets y escritorio.

## 🛠️ Stack Tecnológico
- **Frontend**: HTML5, CSS3 nativo (Variables, Flexbox, CSS Grid) y Vanilla JavaScript.
- **Bundler**: [Vite](https://vitejs.dev/) para un desarrollo rápido y un build optimizado.
- **Tipografía**: Playfair Display (Serif para encabezados), Raleway (Cuerpo del texto) y Montserrat (Etiquetas).

## 💼 Proyectos Destacados
Incluye la visualización de mis últimos proyectos, entre ellos:
- **Ecosistema HelpMeAgro**: Aplicación web (Blazor), API REST (.NET) y aplicación móvil (.NET MAUI).
- **Creador de Contenido con IA**: Plataforma automatizada de generación de vídeos usando Node.js, Remotion, OpenAI y Google Gemini.
- **Vanguard CrossFit**: Suite de aplicaciones de gestión para box de CrossFit (Web, Negocio y Cliente).
- **Herramientas Desktop**: Gestor de Tickets, App de Personal, App OCR con IA en Python.

## 🚀 Instalación y Ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/liskoo1/Portfolio.git
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Construye para producción:
   ```bash
   npm run build
   ```
